## **Fitbit/Google Pixel Watch Data Parser**

**Instructions for Running the Script:**
   - Ensure you have **Python 3** installed.
   - Install the required Python libraries by running:
     ```bash
     pip install pandas tqdm
     ```
   - Place the `parser.py` script in your working directory.
   - Ensure your Fitbit/Google Pixel Watch data files are placed in the appropriate directory (usually `Physical Activity`).
   - Run the script:
     ```bash
     python3 parser.py
     ```
   - The **output CSV files** will be generated in the `output/` directory.

The current version of the parser allows you to run it by typing:

```bash
python3 parser.py
```

**Current Functionality:**
- The parser extracts data from various Fitbit/Google Pixel Watch JSON files (such as `heart_rate-*.json`, `steps-*.json`, etc.).
- It converts the data into **CSV files** with the following categories:
  - Heart Rate
  - Calories
  - Steps
  - Distance
- The extracted data is saved in the `output/` directory as CSV files with the labels `heartrate.csv`, `calories.csv`, `steps.csv`, and `distance.csv`.
- CSV Merging: After parsing, the data from all categories is merged into a single fitbit_data.csv that contains all extracted data.
-	Error Handling: The parser now handles file path errors and data validation, ensuring robustness in case of missing or corrupt files.
- Progress Bar: A tqdm progress bar is added to visually track the progress while parsing files.
